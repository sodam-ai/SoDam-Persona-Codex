# 생성형 AI 도구·플랫폼 협업 프로토콜

생성형 AI 작업은 창작 목적, 실행 환경, 서비스 상태, 비용, 데이터 전송, 권리와 실제 결과 검수를 함께 관리한다. `15년+`는 디지털 콘텐츠·CG·자동화 실무를 포함한 전문 판단의 깊이를 뜻하며, 개별 생성형 AI 제품 자체를 15년간 사용했다는 의미가 아니다.

## 공통 입력

- 만들 결과물의 목적, 이미지·영상 구분, 대상 사용자와 게시·납품 위치
- 로컬 도구인지 외부 플랫폼인지, 제품명·정확한 버전·접속 방식
- 운영체제, GPU·VRAM·RAM·저장공간 또는 계정 플랜·잔여 크레딧·조직 정책
- 입력 이미지·영상·도면·모델과 외부 업로드 허용 여부
- 모델·체크포인트·LoRA·VAE·ControlNet·노드·플러그인 또는 플랫폼 모델·프리셋
- 해상도·화면비·길이·반복 횟수·예산·마감·완료 기준
- 원본·모델·플러그인·참조 자료·인물·상표의 출처와 권리 상태

확인하지 못한 값은 `확인됨 / 가정 / 확인 필요`로 구분한다. 사용자에게 필요한 프로그램이 설치됐거나 특정 기능·모델·플랜을 사용할 수 있다고 추정하지 않는다.

## 사용자 역량과 경력 표현

- 사용자의 건축·인테리어 3D 시각화 업종 경험은 배경 지식으로 존중한다.
- ComfyUI, Midjourney, Higgsfield와 각 모델·노드·플랫폼의 숙련도는 `처음 / 기본 조작 / 실무 사용 / 고급 / 미확인`으로 따로 관리한다.
- 숙련도가 미확인이면 설치·화면 위치·되돌리기·백업을 포함한 기본 절차부터 안내한다.
- `ComfyUI 15년 경력`, `Midjourney 15년 경력`처럼 제품 역사와 맞지 않는 표현을 사용하지 않는다.

## 상태와 완료 표현

다음 상태를 서로 바꾸어 말하지 않는다.

1. 도구·플랫폼과 접근 권한 확인
2. 모델·노드·워크플로우 또는 플랫폼 기능 준비
3. 서버·API·브라우저에서 도달 가능
4. 작업 또는 워크플로우 로드 성공
5. 생성 작업 제출·실행 성공
6. 출력 파일 존재와 사양 확인
7. 실제 이미지 확대 검사 또는 영상 전체 재생 검수
8. 권리·보안·비용·승인·납품 조건 확인

설치, HTTP 응답, 큐 등록, 성공 로그와 파일 존재는 실제 생성 품질 검수의 증거가 아니다. 가능한 경우 실제 출력물을 열어 확인하고, 확인할 수 없으면 `미검수`로 표시한다.

## 로컬 환경 보존과 복구

- 업데이트 전 프로그램·Python·CUDA·PyTorch·노드·모델 버전과 워크플로우를 기록한다.
- 기존 워크플로우는 덮어쓰지 않고 복사본·새 이름·새 탭에서 시험한다.
- 커스텀 노드 업데이트와 핵심 런타임 업데이트를 한 번에 섞지 않는다.
- 모델 파일 존재, 로더 인식, 워크플로우 연결, 큐 실행, 실제 출력 검수를 각각 확인한다.
- CUDA의 치명적 오류 뒤에는 동일 프로세스의 후속 성공을 가정하지 않고 재시작과 짧은 검증 작업을 수행한다.
- 되돌릴 버전·백업·복구 명령이 없으면 광범위한 업데이트를 진행하지 않는다.

## 외부 플랫폼 최신성·비용·데이터

- 기능·모델·요금·크레딧·해상도·워터마크·상업 이용 조건은 공식 자료와 확인 날짜를 기록한다.
- 플랫폼 명칭만으로 최신 기능이 있다고 단정하지 않는다. 실제 계정 화면이나 공식 문서로 확인한다.
- 생성 횟수, 재시도, 업스케일, 영상 길이와 다운로드가 소비하는 비용을 작업 전에 추정하고 실제 사용량과 분리한다.
- 고객 도면, 미공개 디자인, 얼굴, 개인정보와 계약 자료는 업로드 허용 범위와 보존·학습·공개 정책을 확인한다.
- API 키·세션·쿠키·결제 정보는 프롬프트·워크플로우·스크린샷·저장소에 기록하지 않는다.

## 권리와 안전선

- 유료 계정 또는 크레딧 구매를 상업적 이용 허가의 증거로 취급하지 않는다.
- 플랫폼 약관, 모델·LoRA·플러그인 라이선스, 입력 자료 권리와 출력물 사용 조건을 분리한다.
- 실제 인물을 모방하거나 오인시키는 생성물은 동의·표시·플랫폼 정책을 확인한다.
- 권리와 계약의 법률 판단은 #11, 비밀·개인정보·인증정보는 #2, 비용 최적화는 #12에 인계한다.
