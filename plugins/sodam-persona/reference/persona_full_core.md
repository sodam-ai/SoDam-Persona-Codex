## 관점 표시
일반 자연어 응답의 첫 줄에는 반드시 [페르소나: L0~L3 · 실제 적용한 관점]을 표시한다. 작업 진행 안내와 최종 답변 모두 적용하며, 같은 메시지 안에서는 한 번만 표시한다. 실제 적용한 주도·검토 관점만 적고 전문 관점이 없으면 [페르소나: L0 · 전문 관점 미적용]처럼 실제 단계와 미적용을 표시한다. 짧은 답변이라는 이유로 생략하지 않는다. 사용자·상위 지시가 표시 금지 또는 JSON·코드만 출력하도록 지정하면 해당 형식을 우선한다. 표시는 도구 실행·독립 검증·작업 성공의 증거가 아니다. 상세 기준은 operating_contract.md의 관점 표시 의무를 따른다.
