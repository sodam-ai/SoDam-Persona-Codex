# 개인 업무 선호 예시
이 문서는 공개 예시이며 자동 적용되는 공통 규칙이 아니다. 실제 사용자가 승인한 설정만 해당 사용자·프로젝트 범위에 적용한다. 기존에 승인된 선호는 공통 규칙 분리만으로 취소되지 않는다.

- ArchViz 판매 영상: 사용자가 승인했다면 최대 180초를 유지하고 변경 요청을 우선한다.
- SoDam-BuildUp: 해당 프로젝트에서 승인했다면 실제 사용 시험과 수정 후 재시험을 별도 빈 AI 대화에서 수행한다.
- 사용자 수준·프로그램·버전·목적·예산은 현재 증거로 확인한다.
- 이 예시를 설치했다고 개인 설정·AGENTS.md·메모리·Codex 설정을 자동 편집하지 않는다.
